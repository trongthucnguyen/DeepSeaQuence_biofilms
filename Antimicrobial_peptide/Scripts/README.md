# Scripts – Reproducible data analysis and figure generation

This directory contains all scripts used to perform the data analyses and to generate the figures presented in the manuscript:

> **Arctic deep-sea hydrothermal microbiomes as a natural niche for novel antimicrobial peptides**  

Each figure in the manuscript is associated with one or more scripts and corresponding input data files to ensure **full reproducibility**.

---

## General notes

- All scripts are written in **Python**
- Scripts assume the repository structure is preserved
- Input data files are located in the `Data/` directory
- Output figures are generated in the working directory or as specified within each script
- Statistical tests are non-parametric unless otherwise stated

---

## Input data files

The following data files are used for figure generation and statistical analyses:

| Data file | Used in figure(s) |
|---------|------------------|
| `AMP_length.csv` | Fig. 1B |
| `expressed_AMP.csv` | Fig. 3B, Fig. 4 |
| `peptide_test.txt` | Fig. 2 |
| `Predicted_MICs.csv` | Fig. 5A, Fig. 5B |

---

## Figure-to-script mapping

### **Figure 1B – Average length of AMP sequences predicted from nine biofilm samples.**
**Purpose:**  
Visualization of AMP length distributions.

**Script:**  
- `candlestick.py`

**Input data:**  
- `AMP_length.csv`

**Output:**  
- Figure 1B

---

### **Figure 2 – UMAP clustering of antimicrobial peptides**
**Purpose:**  
Visualization of similarity between AMPs predicted from inMAGs and reference peptides from databases.

**Scripts:**  
- `similarity.py`  
  *Generates a similarity matrix between inMAG-derived peptides and reference peptides*
- `plot_umap.py`

**Input data:**  
- `peptide_test.txt`
- `similarity_matrix.tsv` (generated by `similarity.py`)

**Output:**  
- Figure 2

---

### **Figure 3B – Expression profile of antimicrobial peptides across biofilm-derived MAGs.**
**Purpose:**  
Heatmap visualization of expressed AMPs across samples.

**Script:**  
- `heatmapT.py`

**Input data:**  
- `expressed_AMP.csv`

**Output:**  
- Figure 3B

---

### **Figure 4 – Bar plot of the average expression levels of AMPs across samples**
**Purpose:**  
Statistical analysis of AMP expression levels across groups.

**Scripts:**  
- `Kruskal_Wallis.py`  
  *Kruskal–Wallis test*
- `Dunn.py`  
  *Post-hoc Dunn test*

**Input data:**  
- `expressed_AMP.csv`

**Output:**  
- Figure 4

---

### **Figure 5A – Predicted antimicrobial activity results from APEX 1.1**
**Purpose:**  
Bar chart of predicted MIC values based on APEX analysis.

**Script:**  
- `barchart_APEX_number.py`

**Input data:**  
- `Predicted_MICs.csv`

**Output:**  
- Figure 5A

---

### **Figure 5B – Number of AMPs predicted to be active against each pathogen**
**Purpose:**  
Comparison of predicted antimicrobial activities across different pathogenic targets.

**Script:**  
- `barchart_pathogens.py`

**Input data:**  
- `Predicted_MICs.csv`

**Output:**  
- Figure 5B

## Additional statistical analyses (not plotted)

The following scripts perform statistical tests that support the manuscript analyses but do not directly generate figures:

### **Wilcoxon test: AMP class comparison**
**Script:**  
- `wilcoxon_AMP_class.py`

**Purpose:**  
Wilcoxon test to compare the distribution between two AMP classes within inMAG-derived peptides.

---

### **Wilcoxon test: inMAGs vs exMAGs**
**Script:**  
- `wilcoxon_inMAGs_vs_exMAGs.py`

**Purpose:**  
Wilcoxon test to compare peptide properties between peptides derived from inMAGs and exMAGs.

---

## Running the scripts

Scripts can be run individually once the required input data are available.

## Reproducibility statement
All figures and statistical analyses presented in the manuscript can be reproduced using the scripts and data provided in this repository.
All statistical tests, parameters, and assumptions are explicitly documented within the corresponding scripts.
